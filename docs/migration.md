# Rust → Python 移植清单

以 Rust 上游 [qnxg/hnu_query](https://github.com/qnxg/hnu_query) 的 `src` 为行为基准，沿用已有的异步函数与 Pydantic 返回模型。
保留 Rust 模块名；已存在的 `credential` 对应 Rust 的 `ca`，不改名以免破坏调用方。

## 进度

| Rust 模块 | Python 模块 | 范围 | 状态 |
| --- | --- | --- | --- |
| `cas` | `cas` | 登录、RSA、票据、双因子认证、s_ticket | 差异审计完成，上游 TFA 样本与模拟 HTTP 验证 |
| `ca` | `credential` | 凭证登录、预览、下载、成绩排名 | 差异审计完成，上游排名文本与模拟 HTTP 验证 |
| `hdjw` | `hdjw` | 登录、课表、无课表课程、成绩及详情、考试、排名、空教室 | 已完成，Rust 样本与模拟 HTTP 验证 |
| `gym` | `gym` | CAS/直接登录、预约、成绩 | 已完成，Rust 成绩样本与模拟 HTTP 验证 |

所有模块均已有 Python 接口，CAS/凭证的差异审计已完成。
当前完成 Rust 功能移植与离线验证；除研究生系统与暂跳过的 AI 外，各模块均已有至少一条真实登录/查询链路通过。
实际范围包括 CAS 登录、教务排名、个人门户校园卡、新门户账号、本月流量、学工资料、宿舍电量、可信电子凭证排名、空体测预约列表、实验平台学期及 CG 课程列表。
研究生系统需要对应权限；AI 联调受授权入口不可达影响，暂时跳过真实验证。
具体已验证范围与运行方法见 [校园网交互联调](live-check.md)。
保留的 Python 接口差异与兼容性修正见 [维护说明](porting.md)。
