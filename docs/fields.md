# 字段约定

[文档目录](README.md)

## 学年学期

沿用上游命名：`xn` 为学年开始年份，例如 2025–2026 学年的值为 `2025`，不是自然年结束年份。
`xq` 为平台的学期编号：1 秋季、2 春季、3 夏季、4 寒假小学期（研究生系统）。
不同系统的学期 ID 不能互换：实验平台和研究生课表应使用各自 `get_semester()` 返回的 `id`。

## 周次和时间

- 课表 `day` 取 1–7，1 为周一、7 为周日；第 0 周会保留，不自动改成第 1 周。
- 教务课表使用小节编号；空教室查询的 `time` 使用大节编号 1–5，见 [节次表](hdjw/time.md)。
- 新门户 `get_term_info(datetime)` 接受不带时区的 `datetime`，并按 UTC 解释。
- 平台返回的字符串时间通常解析为不带时区的 `datetime`，不会自动推断或换算成本机时区。

## 金额和流量

| 模块 / 字段 | 单位或含义 |
| --- | --- |
| `pt` 校园卡余额、交易金额和交易后余额 | 元 |
| `iportal` 校园卡余额 | 元 |
| `iportal.transaction_amount` | 带正负号的整数分 |
| `netflow` 日/月明细流量 | KB |
| `netflow` 账单下载/上传量 | 字节 |
| `netflow` 账单超额量、套餐量 | GB |
| `netflow` 本月总量、上传量、下载量 | 保留带 `GB` 后缀的字符串，可能含“小于”等文字 |
| `netflow` 比例字段 | 0–1，不是已经乘以 100 的百分数 |
| `wxpay.get_electricity()` | 平台原始字符串，保留“度”“元”等单位 |
| `ai.get_user_remaining_quota()` | 服务端 `data.total_granted`，不自行减去已用量 |

新门户 `MoneyTransfer` 表示实体卡余额同步，统计实际收支时应排除。

## 标识符和空值

- CG 的 `problem.index` 是作业内题目序号，`problem.id` 是题目 ID；读取题目页面使用 `index`。
- 学工的 Python 属性 `class_` 对应 JSON 字段 `class`；学院、专业等代码保留平台原值。
- `None` 不等于零或空列表，例如未绑定邮箱的未读数为 `None`，已绑定且没有未读邮件为 `0`。
- CG 没有课程、作业或题目时返回 `None`，可使用 `result or []` 遍历。
- 字段缺失、空白或没有安排的含义见各模块说明。
