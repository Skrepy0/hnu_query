# 校园网交互联调

[文档目录](README.md)

先连接湖南大学校园网或 VPN，并在项目根目录安装依赖：

```bash
pip install -e ".[dev]"
python scripts/live_check.py
```

脚本在本机询问模块、学号和密码，不通过聊天或命令行参数接收密码。
默认验证 `cas,hdjw`：登录 CAS 后查询教务排名，结果不输出个人信息。
首次联调建议先用默认模块，成功后再逐批选择其他模块。

```bash
python scripts/live_check.py --modules cas,pt,iportal,netflow
```

## 代理与直连

脚本默认沿用 HTTPX 的网络设置，包括 Windows 系统代理。如果已连接校园网/VPN，
但校内入口仍跳转到 WebVPN 校验页，可显式直连：

```bash
python scripts/live_check.py --modules cas,hdjw --direct
```

`--direct` 仅在本次脚本运行中设置 `NO_PROXY=*`，结束后恢复，不修改 Windows 代理配置或库的默认行为。
该模式需要本机本身具备校内访问条件；依赖代理才能访问的系统仍应使用默认模式。

支持文档目录中的全部模块，每个模块执行一项只读查询，以验证登录、请求和解析链路。
不创建或删除 AI Token，不执行预约、充值等业务写入。短信验证需要在本机确认发送。
CAS 登录失败后跳过依赖它的模块，不会自动反复提交密码。

| 模块 | 查询内容 |
| --- | --- |
| `hdjw` | 默认口径的成绩排名 |
| `credential` | 本科主修成绩凭证排名，包含 PDF 提取 |
| `gym` | 体测预约列表及详情 |
| `lab` | 学期列表，需独立密码及可能出现的验证码 |
| `netflow` | 本月流量信息 |
| `pt` | 校园卡资料 |
| `iportal` | 账号资料 |
| `xgxt` | 学工个人资料 |
| `yjsxt` | 研究生学期列表，账号需有权限 |
| `wxpay` | 从学工宿舍资料查询电量 |
| `cg` | 课程列表，需独立密码及验证码 |
| `ai` | `total_granted` 配额字段 |

Windows 下验证码图片会在默认图片应用中打开；其他系统按终端提示打开图片。
未开通某系统、没有宿舍数据或平台暂时不可用，都可能导致对应验证失败，需结合账号权限判断。
一个模块通过只代表上述查询链路通过，不代表该模块所有接口均已线上验证。

默认报告为 `.local/live-check.json`，验证码图片也保存在 `.local`，该目录已被 Git 忽略。
报告仅含模块名、状态、耗时、列表条数、异常类型和 HTTP 状态码；不保存账号、密码、Cookie、
Token、完整响应、成绩或 PDF。可用 `--report` 指定其他报告路径。

报告状态 `waiting_for_input` / `running` 表示尚未完成，`completed` 表示流程结束，
各模块结果仍可能为 `failed` 或 `skipped`。退出码 0 表示所有所选检查通过，1 表示存在失败、跳过或取消。
独立窗口可加 `--pause`，完成后按回车关闭。

凭证首次联调在文件下载阶段返回 400：预览返回的相对路径含目录分隔符，不能将 `/` 编码成 `%2F`。
